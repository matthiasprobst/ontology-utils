= Ontolutils

Describe things and concepts in Python and share their relationships as RDF.
Define models by mapping your fields to ontology terms. Pydantic checks
declared fields; SHACL can check additional requirements on the graph.

== First example

[source,python]
----
from pydantic import Field
from ontolutils import Thing, namespaces, urirefs


@namespaces(prov="http://www.w3.org/ns/prov#", foaf="http://xmlns.com/foaf/0.1/")
@urirefs(Person="prov:Person", firstName="foaf:firstName", lastName="foaf:lastName")
class Person(Thing):
    firstName: str = Field(alias="first_name")
    lastName: str | None = Field(default=None, alias="last_name")

researcher = Person(id="https://example.org/people/ada", first_name="Ada")
assert researcher.firstName == "Ada"
turtle = researcher.serialize("ttl")
----

`turtle` is text. The person uses `http://www.w3.org/ns/prov#Person` and
`http://xmlns.com/foaf/0.1/firstName`; changing HTTP to HTTPS changes those IRIs.
