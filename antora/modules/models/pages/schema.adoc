= Projects and software

Use the fields declared by each model; an extra Python field is not automatically
mapped to RDF. Schema.org models use the `https://schema.org/` namespace.

[source,python]
----
from ontolutils.ex.schema import Project, SoftwareSourceCode

project = Project(name="Flow measurements", url="https://example.org/project")
software = SoftwareSourceCode(
    name="Velocity analysis",
    code_repository="https://example.org/code",
    version="1.0",
)
assert str(software.codeRepository) == "https://example.org/code"
document = software.model_dump_jsonld()
----

`CreativeWork` provides common fields for more specific models. It does not
declare every Schema.org property; for example, arbitrary `title` and
`datePublished` inputs are not guaranteed to appear in the RDF graph.
