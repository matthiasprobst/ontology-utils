= Installation

This guide describes the unreleased 1.0 branch. Use Python 3.11–3.15 and run
the following commands from the branch checkout in a virtual environment.
Pip installs the required versions of Pydantic and RDFLib.

[source,console]
----
python -m pip install .
python -c "import ontolutils; print(ontolutils.__version__)"
----

For the published release, use `python -m pip install ontolutils` in a fresh
environment. Its supported Python versions and API may differ.

Optional packages by feature:

[cols="2,1",options="header"]
|===
| Feature | Packages
| `ontolutils.ex.m4i` numerical variables | `numpy`
| Pint unit conversion | `numpy pint`
| xarray conversion | `numpy pint xarray`
| SHACL graph validation | `pyshacl`
|===

[source,console]
----
python -m pip install numpy pint xarray
python -m pip install pyshacl
----

For contributors, run `python -m pip install -e ".[test]"` in a source checkout.
See the repository's `tests/README.md` and `docs/README.md` for checks and builds.
